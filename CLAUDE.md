## Git Remote Workflow

- `origin`: `https://github.com/CCpoe/new-api.git`
- `upstream`: `https://github.com/QuantumNous/new-api.git`
- Push daily development changes to `origin`.
- To sync upstream, run `git fetch upstream` before merging `upstream/main` into the current integration branch.
- Do not push daily development changes directly to `upstream`.
